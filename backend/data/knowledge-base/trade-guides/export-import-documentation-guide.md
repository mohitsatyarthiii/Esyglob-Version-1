# Export-Import Documentation - Complete Guide 2026

## Overview

Accurate documentation is critical for international trade. This guide covers all documents required for export and import transactions.

## Why Documentation Matters

✅ **Legal Compliance**: Meet regulatory requirements
✅ **Customs Clearance**: Facilitate smooth clearance
✅ **Payment Processing**: Enable payment release
✅ **Dispute Resolution**: Provide evidence
✅ **Record Keeping**: Maintain audit trail

---

## Essential Documents

### 1. Commercial Invoice

**Purpose**: Transaction record and customs declaration

**Required Information**:

| Field | Description |
|-------|-------------|
| **Invoice Number** | Unique identifier |
| **Date** | Issue date |
| **Seller Information** | Name, address, contact |
| **Buyer Information** | Name, address, contact |
| **Product Description** | Detailed description |
| **HS Code** | Product classification |
| **Quantity** | Number of units |
| **Unit Price** | Price per unit |
| **Total Value** | Total amount |
| **Currency** | Transaction currency |
| **Incoterms** | Delivery terms |
| **Payment Terms** | Payment method |
| **Shipping Details** | From/To locations |

**Tips**:
- Use professional format
- Include all required fields
- No errors in calculations
- Keep copies for records

---

### 2. Packing List

**Purpose**: Detailed package contents

**Required Information**:

| Field | Description |
|-------|-------------|
| **Package Number** | Unique per package |
| **Dimensions** | Length × Width × Height |
| **Gross Weight** | Weight including packaging |
| **Net Weight** | Weight excluding packaging |
| **Contents** | What's in each package |


---

### 3. Bill of Lading (Sea Freight)

**Purpose**: Contract of carriage and title document

**Types**:

| Type | Description |
|------|-------------|
| **Straight B/L** | Non-negotiable, named consignee |
| **Order B/L** | Negotiable, can be endorsed |
| **Bearer B/L** | Transferable without endorsement |
| **Surrender B/L** | Electronic release |

**Required Information**:

| Field | Description |
|-------|-------------|
| **Shipper** | Exporter details |
| **Consignee** | Importer details |
| **Notify Party** | To be notified on arrival |
| **Vessel Name** | Name of ship |
| **Voyage Number** | Voyage identifier |
| **Port of Loading** | Departure port |
| **Port of Discharge** | Destination port |
| **Goods Description** | Product details |
| **Number of Packages** | Total packages |
| **Gross Weight** | Total weight |
| **Volume** | Total cubic meters |

---

### 4. Air Waybill (Air Freight)

**Purpose**: Contract of carriage for air freight

**Key Features**:
- Not a title document
- Non-negotiable
- Issued by airline or forwarder
- Unique AWB number for tracking

**Required Information**:

| Field | Description |
|-------|-------------|
| **Shipper** | Exporter details |
| **Consignee** | Importer details |
| **Airport of Departure** | Departure airport |
| **Airport of Destination** | Arrival airport |
| **Flight Details** | Airline and flight number |
| **Goods Description** | Product details |
| **Weight** | Gross weight |
| **Volume** | Total volume |

---

### 5. Certificate of Origin

**Purpose**: Proof of country of manufacture

**Issued By**:
- Chamber of Commerce
- DGFT (India)
- Government authorities

**Types**:

| Type | Description |
|------|-------------|
| **Non-Preferential** | For general use |
| **Preferential** | For FTA benefits |
| **GSP Certificate** | For GSP benefits |

**Required Information**:

| Field | Description |
|-------|-------------|
| **Exporter** | Exporter details |
| **Consignee** | Importer details |
| **Product Description** | What's being exported |
| **HS Code** | Product classification |
| **Quantity** | Amount being exported |
| **Origin Criteria** | How origin is established |
| **Signature** | Authorized signatory |

---

### 6. Export/Import License

**Purpose**: Required for restricted goods

**When Required**:
- Controlled products
- Restricted destinations
- Strategic goods
- Regulatory compliance

**Application Process**:
1. Identify licensing requirement
2. Complete application
3. Submit required documents
4. Pay fee
5. Receive license

---

### 7. Insurance Certificate

**Purpose**: Evidence of insurance coverage

**Required Information**:

| Field | Description |
|-------|-------------|
| **Insured Party** | Who is covered |
| **Vessel Name** | Ship/aircraft details |
| **Goods Description** | What's being insured |
| **Sum Insured** | Coverage amount |
| **Premium Paid** | Insurance cost |
| **Coverage Type** | All risks, WA, FPA |
| **Validity Period** | Coverage dates |

## Common Documentation Mistakes

| Mistake | Consequence | Prevention |
|---------|-------------|------------|
| **Incorrect HS Code** | Customs delays, penalties | Verify classification |
| **Value Errors** | Duty miscalculation | Double-check amounts |
| **Missing Documents** | Customs hold | Use checklist |
| **Spelling Errors** | Identity issues | Verify all names |
| **Wrong Incoterms** | Risk/cost issues | Confirm terms |
| **Signing Errors** | Invalid documents | Check signatures |
