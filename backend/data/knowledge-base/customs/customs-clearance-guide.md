# Customs Clearance - Complete B2B Guide 2026

## Overview

Customs clearance is a critical step in international trade. This guide covers everything B2B businesses need to know about clearing goods through customs.

## What is Customs Clearance?

Customs clearance is the process of getting goods through customs authorities when importing or exporting.

### Key Objectives

1. **Compliance**: Meet all legal requirements
2. **Duty Assessment**: Determine applicable duties
3. **Security**: Prevent illegal imports/exports
4. **Trade Facilitation**: Efficient processing

---

## Customs Process Flow

### Import Customs Process

**Step 1: Pre-Arrival**
- Importer files advance information
- Customs performs risk assessment
- Target for inspection

**Step 2: Arrival**
- Cargo arrives at port/airport
- Carrier files manifest
- Goods unloaded

**Step 3: Entry Filing**
- Importer/customs broker files entry
- HS code classification
- Value declaration
- Duty calculation

**Step 4: Assessment**
- Customs reviews documents
- May request additional info
- May select for inspection

**Step 5: Payment**
- Duties and taxes calculated
- Payment processed

**Step 6: Release**
- Goods released
- Available for delivery

**Step 7: Post-Entry**
- Records maintained
- Potential audit
- Compliance verification

### Export Customs Process

**Step 1: Pre-Export**
- Documentation prepared
- Export license (if required)

**Step 2: Declaration**
- Export declaration filed
- Shipping bill submitted

**Step 3: Assessment**
- Customs reviews documents
- Inspection (selective)

**Step 4: Clearance**
- Goods cleared for export
- Let Export Order granted

**Step 5: Loading**
- Goods loaded on vessel/aircraft

## HS Code Classification

### What is HS Code?

Harmonized System (HS) Code is an international product classification system.

**Structure**:
- 6-digit international code
- 6-10 digits with country-specific

**HS Code Example**:

| Code | Description |
|------|-------------|
| **7208** | Flat-rolled products of iron/steel |
| **7208.10** | Not further worked than hot-rolled |
| **7208.10.10** | Width ≥ 600 mm, thickness ≥ 4.75 mm |

### Classification Process

1. **Identify Product**: What is the product?
2. **Check Description**: Find in HS
3. **Verify Specifics**: Check dimensions, composition
4. **Apply Rules**: Use General Interpretative Rules
5. **Get Ruling**: Binding ruling if needed

### Common Classification Mistakes

| Mistake | Consequence |
|---------|-------------|
| **Wrong Category** | Incorrect duties |
| **Insufficient Detail** | Classification delays |
| **Mixing Products** | Multiple codes needed |
| **Ignoring Modifications** | Updated HS changes |

## Duty Calculation

### Duty Components

| Component | Description |
|-----------|-------------|
| **CIF Value** | Cost, Insurance, Freight |
| **Duty Rate** | Based on HS code |
| **Multipliers** | Additional duties |
| **VAT/GST** | Value-added tax |
| **Other Charges** | Fees, surcharges |

### Example Calculation

**Import: Steel Coils to USA**

| Component | Amount | Rate | Duty |
|-----------|--------|------|------|
| FOB Value | $10,000 | - | - |
| + Freight | $1,000 | - | - |
| + Insurance | $200 | - | - |
| = CIF Value | $11,200 | - | - |
| × Duty Rate (5%) | $11,200 | 5% | $560 |
| + Anti-Dumping Duty | $11,200 | 10% | $1,120 |
| + VAT | $11,200 | 0% | $0 |
| **Total Duties** | - | - | **$1,680** |

## Customs Penalties

### Common Violations

| Violation | Penalty |
|-----------|---------|
| **Misclassification** | 100% duty + fines |
| **Under-valuation** | 100-300% duty + fines |
| **False Origin** | 2x duty + fines |
| **Missing Documents** | $1,000-10,000 |
| **Late Filing** | Interest/penalties |

### Avoiding Penalties

✅ **Use Correct HS Code**: Verify classification
✅ **Declare Correct Value**: Market value
✅ **Complete Documentation**: All required forms
✅ **Maintain Records**: Keep for 5+ years
✅ **Use Customs Broker**: Professional assistance
