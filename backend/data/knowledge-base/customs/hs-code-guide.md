# HS Code - Complete Guide for B2B Businesses

## Overview

The Harmonized System (HS) Code is the international standard for product classification. This guide explains everything B2B businesses need to know about HS Codes.

## What is an HS Code?

HS Code is a standardized numerical system for classifying traded products.

**Key Facts**:
- **Developed by**: WCO (World Customs Organization)
- **Used by**: 200+ countries
- **Structure**: 6-10 digit code
- **Purpose**: Tariff classification, statistics

---

## HS Code Structure

### International Format (6 digits)

| Level | Digits | Description | Example |
|-------|--------|-------------|---------|
| **Chapter** | 2 | Broad category | 72 (Iron/Steel) |
| **Heading** | 4 | Sub-category | 7208 (Flat-rolled) |
| **Subheading** | 6 | Specific product | 720810 (Hot-rolled) |

### Country-Specific Format

| Level | Digits | Description | Example |
|-------|--------|-------------|---------|
| **International HS** | 6 | Global standard | 720810 |
| **US HTS** | 8-10 | US-specific | 7208100010 |
| **EU TARIC** | 8-10 | EU-specific | 7208100010 |
| **Indian HS** | 8 | India-specific | 72081000 |

## Country-Specific Variations

### USA (HTSUS)

**Structure**: 10 digits
**Example**: 7208.10.0010

**Special Rules**:
- Additional duty codes
- Trade agreement codes

### EU (TARIC)

**Structure**: 10 digits
**Example**: 7208.10.0010

**Special Rules**:
- Anti-dumping codes
- Tariff quotas

### India

**Structure**: 8 digits
**Example**: 7208.10.00

**Special Rules**:
- Customs duty rates
- Licencing requirements
