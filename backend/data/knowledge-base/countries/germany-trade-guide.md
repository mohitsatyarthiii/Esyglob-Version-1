## Trade Regulations

### Customs Procedures

| Requirement | Details |
|-------------|---------|
| **Customs Authority** | German Customs (Zoll) |
| **Declaration** | ATLAS system (electronic) |
| **Authorized Use** | AEO status available |
| **VAT** | 19% (standard) 7% (reduced) |
| **Simplification** | Central clearance |

### Import Requirements

**Documents Required**:
- Commercial Invoice
- Packing List
- Bill of Lading/AWB
- Certificate of Origin
- Import License (if required)
- Product Certifications (CE, etc.)

**VAT on Imports**:
| Type | Rate |
|------|------|
| **Standard** | 19% |
| **Reduced** | 7% |
| **Special** | 5% (some goods) |
