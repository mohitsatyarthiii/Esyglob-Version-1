# How to List Products on EsyGlob - Step by Step Tutorial

## Overview

This tutorial will guide you through the complete product listing process on EsyGlob B2B marketplace.

## Prerequisites

Before starting, ensure you have:

- ✅ Verified EsyGlob seller account
- ✅ High-quality product images
- ✅ Product specifications ready
- ✅ Pricing information
- ✅ Certifications (if applicable)

---

## Step 1: Access Product Dashboard

**Action**: Login to your EsyGlob account

**Path**:
1. Go to esyglob.com
2. Click "Sign In"
3. Enter your credentials
4. Click "Dashboard" 
5. Navigate to "Products" section

**Navigation Menu**:

Dashboard
├── Orders
├── Products
│ ├── Add New Product
│ ├── Manage Products
│ └── Categories
├── Messages
└── Settings


---

## Step 2: Click "Add New Product"

**Action**: Click the "Add New Product" button

**Location**:
- Top right corner of Products page
- Blue "Add New Product" button

---

## Step 3: Fill Basic Information

**Action**: Complete the basic product details

### Product Name

**Best Practices**:
- ✅ Clear and descriptive
- ✅ Include key features
- ✅ Include brand/model if applicable
- ✅ Include HS code if possible

**Bad Examples**:
- ❌ "Product" (too generic)
- ❌ "Item" (not descriptive)
- ❌ "Best Product" (subjective)

**Good Examples**:
- ✅ "Stainless Steel 304 Grade Cold Rolled Coil - 0.5mm Thickness"
- ✅ "Organic Cotton T-Shirt - 100% Cotton, 180 GSM"
- ✅ "Industrial Electric Motor - 5 HP, 3 Phase, 1440 RPM"

### Product Description

**What to Include**:

1. **Overview**: What is the product?
2. **Features**: Key specifications
3. **Benefits**: Why choose this product?
4. **Applications**: What is it used for?
5. **Quality Standards**: Certifications
6. **Packaging**: How is it packed?
7. **Warranty**: Any guarantee?


**Character Limit**: 500-2000 words recommended

---

## Step 4: Select Product Category

**Action**: Choose the correct category for your product

**Category Selection**:
1. Click "Select Category"
2. Browse or search for category
3. Choose the most specific category
4. Add subcategories if applicable


**Tips**:
- Choose specific category for better visibility
- Don't choose generic categories
- Multiple categories allowed for relevant products

---

## Step 5: Add HS Code

**Action**: Enter the correct HS Code

**HS Code Format**: 
- 6-10 digit international code
- First 6 digits are standard
- Additional digits for country-specific

**Finding HS Code**:
1. Use HS Code search tool
2. Check with customs broker
3. Refer to international HS database
4. Use EsyGlob's HS Code lookup

**Example HS Codes**:
- Steel Coils: 7208, 7209
- Cotton T-shirts: 6109
- Electric Motors: 8501

---

## Step 6: Upload Product Images

**Action**: Upload high-quality product images

**Image Requirements**:

| Requirement | Details |
|-------------|---------|
| **Minimum Size** | 800 x 800 pixels |
| **Maximum Size** | 10 MB per image |
| **Format** | JPG, JPEG, PNG |
| **Number** | Minimum 3, Maximum 20 |
| **Background** | White or neutral |

**Image Types to Include**:

1. **Main Image**: Front view, clean background
2. **Product Details**: Close-up of features
3. **Dimensions**: With measurements
4. **Packaging**: How it's packed
5. **Applications**: Product in use
6. **Certifications**: Any certificates
7. **Video**: Product demonstration (optional)

**Image Tips**:
- ✅ Use professional lighting
- ✅ Show product from multiple angles
- ✅ Include size reference
- ✅ Highlight key features
- ❌ No watermarks
- ❌ No blurry images
- ❌ No stock photos

---

## Step 7: Set Pricing

**Action**: Set your product pricing

### Price Configuration

| Field | Description |
|-------|-------------|
| **Unit Price** | Price per unit |
| **Currency** | Select currency (USD, EUR, GBP, INR) |
| **MOQ** | Minimum Order Quantity |
| **Volume Discounts** | Discounts for larger quantities |

### Volume Discount Setup

**Example**:
| Quantity | Price/Unit |
|----------|------------|
| 100-499 | $50.00 |
| 500-999 | $45.00 |
| 1000+ | $40.00 |

### Pricing Strategy Tips

✅ **Factor All Costs**:
- Production cost
- Shipping cost
- Platform fees (1-3%)
- Payment fees (1.5-2%)
- Profit margin

✅ **Research Market Prices**:
- Check competitor pricing
- Compare similar products
- Adjust based on quality

✅ **Consider Currency**:
- USD is recommended
- Show prices in multiple currencies
- Update regularly

## Step 8: Enter Product Specifications

**Action**: Add detailed product specifications

### Required Specifications

| Specification | Description |
|---------------|-------------|
| **Brand** | Brand name |
| **Model Number** | Product model |
| **Material** | Material composition |
| **Color** | Available colors |
| **Dimensions** | Size, length, width, height |
| **Weight** | Product weight |
| **Power** | Power requirements (electrical) |
| **Capacity** | Capacity (if applicable) |

### Product-Specific Specifications

**For Steel Products**:
| Specification | Value |
|---------------|-------|
| Grade | 304, 316, etc. |
| Thickness | 0.5mm, 1mm, etc. |
| Width | 1000mm, 1200mm, etc. |
| Coil Weight | 5-10 MT |
| Surface Finish | 2B, BA, No.4 |

**For Textiles**:
| Specification | Value |
|---------------|-------|
| Fiber Content | 100% Cotton |
| GSM | 180 |
| Width | 60 inches |
| Color | White, Black, etc. |
| Weave | Plain, Twill |

## Step 9: Add Shipping Information

**Action**: Configure shipping details

### Shipping Settings

| Field | Description |
|-------|-------------|
| **Shipping Method** | Sea, Air, Express, Rail |
| **Shipping Terms** | FOB, CIF, DDP, etc. |
| **Shipping Origin** | Country of dispatch |
| **Shipping Time** | Estimated delivery time |
| **Packaging Details** | How products are packed |
| **Weight** | Product weight for shipping |

### Shipping Terms Explanation

| Term | Meaning |
|------|---------|
| **FOB** | Free on Board - Buyer pays shipping |
| **CIF** | Cost, Insurance, Freight - Seller pays |
| **DDP** | Delivered Duty Paid - Seller pays all |
| **EXW** | Ex Works - Buyer handles everything |
