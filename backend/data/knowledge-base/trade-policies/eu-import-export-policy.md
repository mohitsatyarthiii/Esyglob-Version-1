# EU Import-Export Policy - Complete Guide 2026

## Overview

The European Union has a unified customs territory with common policies across 27 member states. This guide covers all essential policies for B2B traders.

## Legal Framework

### Key Legislation

| Legislation | Purpose | Authority |
|-------------|---------|-----------|
| **Union Customs Code (UCC)** | Customs procedures | European Commission |
| **Common Customs Tariff** | Duty rates | European Commission |
| **REACH** | Chemicals regulation | ECHA |
| **RoHS Directive** | Hazardous substances | European Commission |
| **WEEE Directive** | E-waste | European Commission |

### Regulatory Authorities

| Authority | Role |
|-----------|------|
| **European Commission** | Policy making |
| **National Customs Authorities** | Implementation |
| **ECHA (European Chemicals Agency)** | REACH implementation |
| **European Medicines Agency** | Pharmaceutical regulation |
| **EFSA** | Food safety |

## Import Policy

### Single Customs Territory

- Unified tariff across all 27 member states
- Free movement of goods within EU
- Common external tariff

### Import Procedures

**Steps**:
1. **Customs Declaration**: Electronic filing
2. **Classification**: TARIC code
3. **Valuation**: Transaction value
4. **Duty Payment**: VAT & duties
5. **Release**: Goods released

## Customs Documents

### Required Documents

| Document | Purpose |
|----------|---------|
| **Customs Declaration** | Entry filing |
| **Commercial Invoice** | Transaction details |
| **Packing List** | Package details |
| **Bill of Lading/Air Waybill** | Transport document |
| **Certificate of Origin** | Origin proof |
| **Import License** | Restricted goods |
| **CE Certificate** | Product compliance |

### Single Administrative Document (SAD)

**Purpose**: Combined declaration for customs
**Format**: Electronic only (EU-wide)
**Valid**: All 27 member states

## Tariff Structure

### Common Customs Tariff (CCT)

**Types of Duty**:

| Duty Type | Description |
|-----------|-------------|
| **Ad Valorem** | Percentage of value |
| **Specific** | Fixed amount per unit |
| **Compound** | Combination |
| **Agricultural Levy** | Agricultural products |
| **Anti-dumping** | Unfair imports |

### TARIC Classification

**Structure**: 10-digit code
- First 6: International HS
- Next 2: EU-specific
- Last 2: Additional codes

### Duty Rates by Product

| Product Category | Typical Rate |
|------------------|--------------|
| **Electronics** | 0-10% |
| **Machinery** | 0-8% |
| **Textiles** | 5-12% |
| **Automotive** | 10-25% |
| **Chemicals** | 0-6% |
| **Pharmaceuticals** | 0-5% |

## VAT in the EU

### VAT System

| Country | Standard Rate |
|---------|---------------|
| **Germany** | 19% |
| **France** | 20% |
| **Italy** | 22% |
| **Spain** | 21% |
| **Netherlands** | 21% |
| **Poland** | 23% |

### VAT on Imports

**Payment**:
- At point of import
- Registered businesses: Reverse charge
- Deferral possible

### Intrastat Reporting

**Thresholds**:
- Arrivals: €1,000,000+
- Dispatches: €1,000,000+

## Export Policy

### Export Procedures

1. **Declaration**: Electronic export declaration
2. **Export License**: If required
3. **Customs Clearance**: At export point
4. **Export Release**: Goods can leave

### Export Controls

| Category | Regulatory Authority |
|----------|---------------------|
| **Dual-use Goods** | National authorities |
| **Military Goods** | National authorities |
| **Sanctioned Goods** | EU sanctions |

## Product Compliance

### CE Marking

**Products**:
- Electronics
- Machinery
- Toys
- Medical devices
- Construction products

**Requirements**:
- Product testing
- Technical documentation
- Declaration of Conformity
- CE marking on product

### REACH (Registration, Evaluation, Authorization of Chemicals)

**Purpose**: Chemical safety
**Applies**: All chemical substances
**Registration**: ECHA

**Requirements**:
- Registration of substances
- Safety Data Sheets
- Authorization for SVHCs
- Supply chain communication

### RoHS (Restriction of Hazardous Substances)

**Substances**:
- Lead (Pb) ≤0.1%
- Mercury (Hg) ≤0.1%
- Cadmium (Cd) ≤0.01%
- Hexavalent Chromium ≤0.1%
- PBB ≤0.1%
- PBDE ≤0.1%

### WEEE (Waste Electrical & Electronic Equipment)

**Purpose**: E-waste management
**Requirements**:
- Producer registration
- Labeling requirement
- Collection/recycling obligations
- Waste disposal reporting

### EU FTAs

| Agreement | Partners | Status |
|-----------|----------|--------|
| **EU-UK Trade Agreement** | UK | Active |
| **EU-Canada CETA** | Canada | Active |
| **EU-Japan EPA** | Japan | Active |
| **EU-Vietnam FTA** | Vietnam | Active |
| **EU-Korea FTA** | South Korea | Active |
| **EU-Mercosur** | 4 LatAm | Negotiation |
| **EU-India FTA** | India | Negotiation |

### GSP (Generalized System of Preferences)

**Beneficiaries**: Developing countries
**Types**:
- Standard GSP
- GSP+ (Enhanced)
- EBA (Everything But Arms)

**Benefits**:
- Duty reduction/removal
- Facilitated trade

## Customs Procedures

### Customs Declaration

**Electronic Declarations**:
- Single Window environment
- Automated processing
- Risk-based targeting

### Authorized Economic Operator (AEO)

**Status**: Trusted trader certification
**Benefits**:
- Fewer controls
- Priority treatment
- Simplified procedures

### Customs Bond

| Type | Amount | Requirement |
|------|--------|-------------|
| **Comprehensive Guarantee** | Based on duties | Regular importers |
| **Single Guarantee** | Per transaction | Occasional importers |

## Compliance and Penalties

### Common Violations

| Violation | Penalty |
|-----------|---------|
| **Incorrect Classification** | Duty + 15-50% |
| **Under-valuation** | 1-2x duty + penalties |
| **Missing Documentation** | Delay + penalties |
| **REACH Non-compliance** | Up to €1,000,000 |
| **RoHS Violation** | Up to €100,000 |

## Carbon Border Adjustment Mechanism (CBAM)

### Overview

**Purpose**: Prevent carbon leakage
**Start**: 2026 (transitional)
**Full Implementation**: 2026-2029

**Products Covered**:
- Steel
- Aluminum
- Cement
- Fertilizer
- Electricity
- Hydrogen

### CBAM Process

| Stage | Description |
|-------|-------------|
| **Reporting** | Carbon emissions reporting |
| **Certificate Purchase** | Buy CBAM certificates |
| **Compliance** | Meet carbon standards |

### Impact on Importers
- Additional costs for carbon-intensive products
- Reporting requirements
- Compliance obligations
