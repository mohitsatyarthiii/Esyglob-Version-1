# Sanctions and Export Controls - Complete Guide 2026

## Overview

Sanctions and export controls are critical compliance areas for international trade. This guide covers all essential regulations for B2B businesses.

## Types of Sanctions

### Economic Sanctions

| Type | Description | Examples |
|------|-------------|----------|
| **Comprehensive** | Full trade embargo | Iran, North Korea |
| **Targeted** | Specific entities/individuals | Designated persons |
| **Sectoral** | Specific industries | Russia (financial) |
| **Smart Sanctions** | Travel, asset freezes | Political leaders |

### International Sanctions

| Source | Authority | Examples |
|--------|-----------|----------|
| **UN** | UN Security Council | North Korea, Iran |
| **US** | OFAC, BIS | Cuba, Syria, Iran |
| **EU** | Council Decisions | Russia, Myanmar |
| **India** | Government orders | Specific entities |
| **UK** | OFSI | Russia sanctions |

## Export Controls

### US Export Controls

**BIS (Bureau of Industry and Security)**
- Controls dual-use goods
- EAR (Export Administration Regulations)
- ECCN classification

**ECCN Classification**:

| ECCN Code | Product Category |
|-----------|------------------|
| **0Axxx** | Nuclear materials |
| **1Axxx** | Chemicals |
| **3Axxx** | Electronics |
| **9Axxx** | Aerospace/Defense |

**Licensing Requirements**:

| Category | Requirement |
|----------|-------------|
| **NLR (No License Required)** | EAR99 goods |
| **License Required** | Controlled goods |
| **Prohibited** | Sanctioned destinations |

### EU Export Controls

**Dual-Use Regulation**:
- List of controlled goods
- Requires authorization
- End-use monitoring

### Wassenaar Arrangement

**Purpose**: Export controls
**Members**: 42 countries
**Coverage**: Conventional weapons
**Dual-use goods**

## Compliance Requirements

### Screening Requirements

**Who to Screen**:
- New customers
- Existing customers (regular)
- Partners and distributors
- End users

**When to Screen**:
- Before first transaction
- Regular intervals (quarterly)
- When sanctions change
- When customer details change

### Due Diligence Checklist

| Check | Description |
|-------|-------------|
| **Sanctions List Check** | Screen all parties |
| **PEP Check** | Politically exposed persons |
| **Adverse Media** | Negative information |
| **End Use Check** | Legitimate use |
| **Country Risk** | Sanctioned countries |

## Consequences of Violations

### Penalties

**US Penalties**:

| Violation Type | Criminal Fine | Civil Penalty |
|----------------|---------------|---------------|
| **Negligence** | Up to $250,000 | Up to $300,000 |
| **Willful** | Up to $1,000,000 | Up to $1,000,000 |
| **Corporation** | Up to $20,000,000 | Varies |

### Other Consequences

| Consequence | Description |
|-------------|-------------|
| **Reputational Damage** | Loss of trust |
| **Loss of License** | Export privileges |
| **Prosecution** | Criminal charges |
| **Financial Loss** | Fines and forfeitures |
| **Business Disruption** | Supply chain impact |
