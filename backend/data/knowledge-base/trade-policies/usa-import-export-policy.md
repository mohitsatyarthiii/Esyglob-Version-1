# USA Import-Export Policy - Complete Guide 2026

## Overview

The United States has a comprehensive legal framework governing import and export activities. This guide covers all essential policies for B2B traders.

## Legal Framework

### Key Legislations

| Legislation | Purpose | Authority |
|-------------|---------|-----------|
| **Tariff Act of 1930** | Customs duties | CBP |
| **Trade Act of 1974** | Trade agreements | USTR |
| **Customs Modernization Act** | Customs procedures | CBP |
| **Export Control Reform Act** | Export controls | BIS |
| **International Emergency Economic Powers Act** | Sanctions | OFAC |

### Regulatory Authorities

| Authority | Role |
|-----------|------|
| **CBP (Customs and Border Protection)** | Customs enforcement |
| **BIS (Bureau of Industry and Security)** | Export controls |
| **OFAC (Office of Foreign Assets Control)** | Sanctions |
| **FCC** | Electronics regulation |
| **FDA** | Food and drug regulation |
| **CPSC** | Consumer product safety |

## Import Policy

### Import Requirements

**Basic Requirements**:
1. Customs entry filed
2. Duties paid
3. Compliance with regulations
4. Proper documentation

**Entry Types**:

| Type | Value Threshold | Use |
|------|-----------------|-----|
| **Formal Entry** | >$2,500 | Most commercial imports |
| **Informal Entry** | ≤$2,500 | Small shipments |
| **Section 321** | ≤$800 | Duty-free de minimis |

### Required Documents

| Document | Purpose |
|----------|---------|
| **Commercial Invoice** | Transaction details |
| **Packing List** | Package details |
| **Bill of Lading/Air Waybill** | Transport document |
| **Entry Summary (CBP Form 3461)** | Customs declaration |
| **HS Classification** | Product classification |
| **Country of Origin Certificate** | Origin proof |
| **Importer Security Filing (ISF)** | Security filing |

## Import Duties

### Duty Structure

**Types of Duties**:

| Duty Type | Purpose |
|-----------|---------|
| **Ad Valorem** | Percentage of value |
| **Specific Duty** | Fixed amount per unit |
| **Compound Duty** | Combination of above |
| **Dumping Duties** | Anti-dumping |
| **Countervailing Duties** | Subsidies |

### HTSUS Classification

**Structure**: 10-digit code
- First 6: International HS
- Last 4: US-specific

### Section 301 Tariffs (China)

| List | Value | Rate | Products |
|------|-------|------|----------|
| **List 1** | $50B | 25% | Medical, machinery |
| **List 2** | $50B | 25% | Electronics, plastics |
| **List 3** | $200B | 25% | Consumer goods |
| **List 4A** | $120B | 15% | All remaining |

### Section 232 Tariffs

| Product | Rate |
|---------|------|
| **Steel** | 25% |
| **Aluminum** | 10% |

  - 9A001: Aerospace
  - 1A004: Chemicals

## Customs Clearance Process

### Import Clearance

**Step 1**: Pre-arrival
- File ISF 24 hours before
- Prepare documentation

**Step 2**: Arrival
- Cargo arrives
- Carrier files manifest

**Step 3**: Entry Filing
- Customs broker files entry
- CBP Form 3461

**Step 4**: Assessment
- CBP reviews documents
- Duties calculated

**Step 5**: Payment
- Duties paid
- Other fees paid

**Step 6**: Release
- Cargo released
- Available for pickup

### Customs Broker

**Role**:
- Filing entries
- Advising on compliance
- Classification assistance
- Rate determination

**Requirements**:
- Licensed by CBP
- Annual $100,000 bond
- Knowledge of regulations

## Compliance and Penalties

### Common Violations

| Violation | Penalty |
|-----------|---------|
| **Misclassification** | Duty difference + penalties |
| **Under-valuation** | 100-300% of duty |
| **False Origin** | 2x duty + penalties |
| **No Entry Filing** | Double duties |
| **Late Filing** | $1,000-10,000 |
| **Sanctions Violation** | $250,000+ penalties |

### Penalty Structure

| Category | Maximum Fine |
|----------|--------------|
| **Negligence** | 2x duty |
| **Gross Negligence** | 4x duty |
| **Fraud** | 8x duty |
| **Criminal Penalties** | $250,000+ |
