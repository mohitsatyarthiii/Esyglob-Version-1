# EsyGlob Seller Guide - Complete Walkthrough

## Introduction

Welcome to EsyGlob! This comprehensive guide will help you navigate the platform as a seller and grow your international business.

## Account Setup

### Step 1: Registration

**How to Register**:
1. Go to esyglob.com
2. Click "Sign Up" button
3. Enter your business email
4. Create a strong password
5. Select "Seller" role
6. Choose your business type:
   - Manufacturer
   - Exporter
   - Trader
7. Agree to Terms & Conditions
8. Click "Create Account"

### Step 2: Business Verification

**Verification Levels**:

| Level | Requirements | Benefits |
|-------|--------------|----------|
| **Basic** | Email, phone verification | Limited listings |
| **Standard** | Business registration, tax ID | 200 listings |
| **Premium** | Factory audit, ISO certified | Unlimited listings |

**Required Documents for Standard Verification**:

| Document | Purpose |
|----------|---------|
| **Business Registration** | Legal entity proof |
| **GST/Tax Registration** | Tax compliance |
| **Import Export Code (IEC)** | Export capability |
| **PAN Card** | Tax identification |
| **Bank Account Details** | Payment processing |
| **Business Address Proof** | Physical presence |
| **Product Certifications** | Quality validation |

**Premium Verification Additional Documents**:
- Factory audit report
- ISO certification
- Quality management system
- Export history records
- Trade references
- Social compliance audit

### Step 3: Verification Process

**Timeline**:
| Verification Type | Duration |
|-------------------|----------|
| **Basic** | 24-48 hours |
| **Standard** | 3-5 business days |
| **Premium** | 5-10 business days |

**During Verification**:
1. Document submission
2. Document verification
3. Business legitimacy check
4. Quality assessment
5. Approval/Rejection

**Step 1**: Go to Dashboard
**Step 2**: Click "Add New Product"
**Step 3**: Complete Product Details

**Product Details Required**:

| Field | Description |
|-------|-------------|
| **Title** | Clear, descriptive name |
| **Description** | Detailed product information |
| **Category** | Select correct category |
| **HS Code** | International classification |
| **Images** | High-quality photos (6+) |
| **Price** | Unit price in USD/EUR |
| **MOQ** | Minimum Order Quantity |
| **Certifications** | Display all certifications |
| **Packing Details** | Packaging information |
| **Lead Time** | Production and shipping time |
| **Shipping Terms** | FOB, CIF, etc. |
| **Payment Terms** | T/T, L/C, etc. |

**Image Requirements**:
- Minimum 800x800 pixels
- JPEG or PNG format
- Multiple angles
- Product only (no watermarks)
- Professional lighting

## Managing Orders

### Order Workflow

**Order Lifecycle**:

| Stage | Action | Timeline |
|-------|--------|----------|
| **1. Order Received** | Acknowledge order | Within 24 hours |
| **2. Confirm Details** | Verify specifications | 1-2 days |
| **3. Production** | Manufacture goods | Varies |
| **4. Quality Check** | QC process | 1-3 days |
| **5. Shipping** | Package and ship | 2-5 days |
| **6. Documentation** | Prepare export docs | 2-3 days |
| **7. Delivery** | Goods delivered | Varies |
| **8. Completion** | Order complete | Buyer confirms |

### Quality Management

**Quality Control Steps**:

1. **Raw Material Inspection**
   - Check incoming materials
   - Verify specifications
   - Document findings

2. **In-Process Quality Control**
   - Monitor during production
   - Check critical points
   - Maintain records

3. **Pre-Shipment Inspection**
   - 100% inspection
   - AQL sampling
   - Documentation

4. **Third-Party QC**
   - Use certified labs
   - SGS, Bureau Veritas, TÜV

**Quality Certifications to Display**:
- ISO 9001
- ISO 14001
- Product-specific (CE, UL, RoHS)
