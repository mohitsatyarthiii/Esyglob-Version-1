# EsyGlob Dispute Resolution - Complete Guide

## Overview

EsyGlob provides a fair, transparent, and efficient dispute resolution system to resolve conflicts between buyers and sellers.

## Understanding Disputes

### Common Dispute Types

| Type | Description | Examples |
|------|-------------|----------|
| **Non-Delivery** | Goods not received | Lost shipment, non-shipment |
| **Quality Issues** | Product not as described | Defective goods, wrong specifications |
| **Quantity Issues** | Incorrect quantity | Short shipment, extra items |
| **Shipping Damage** | Goods damaged in transit | Physical damage, water damage |
| **Payment Issues** | Payment problems | Fraud, unauthorized charges |
| **Delivery Delays** | Late delivery | Exceeding promised timeframe |

### Dispute Causes

**Buyer Disputes**:
- Product doesn't match description
- Quality below standard
- Late delivery
- Wrong items received
- Damaged goods

**Seller Disputes**:
- Buyer hasn't paid
- Buyer claims false issues
- Buyer damaged goods
- Buyer returned wrong items

## Dispute Process Flow

### Step 1: Communication

**Initial Contact**:
1. Buyer contacts seller
2. Explain the issue clearly
3. Provide evidence (photos, documents)
4. Request resolution
5. Document all communication

**Seller Response**:
1. Acknowledge the issue
2. Investigate the problem
3. Propose solution
4. Communicate resolution
5. Document communication

### Step 2: Resolution Attempt

**Seller Proposed Resolutions**:

| Resolution | Description |
|------------|-------------|
| **Replacement** | New goods shipped |
| **Partial Refund** | Part of payment returned |
| **Full Refund** | All payment returned |
| **Compensation** | Discount on future order |
| **Return** | Goods returned to seller |

**Buyer Responses**:
- Accept proposed solution
- Negotiate alternative
- Escalate to platform

### Step 3: Platform Mediation

**When to Escalate**:
1. Seller doesn't respond (48 hours)
2. Agreement can't be reached
3. Seller refuses resolution
4. Buyer not satisfied

**How to Escalate**:
1. Go to "Claims Center"
2. Click "File Dispute"
3. Select dispute type
4. Provide all evidence
5. Describe the issue
6. Submit claim

### Step 4: Investigation

**Platform Review**:
1. Review all evidence
2. Contact both parties
3. Gather additional information
4. Analyze transaction records
5. Make informed decision

**Evidence Required**:

| Evidence Type | Examples |
|---------------|----------|
| **Communication** | Emails, chat messages |
| **Photos/Videos** | Product images, damage photos |
| **Documents** | Invoices, shipping records |
| **Certificates** | Quality certificates |
| **Tracking** | Shipping tracking info |

### Step 5: Decision

**Possible Decisions**:

| Decision | Description |
|----------|-------------|
| **Buyer Wins** | Full/partial refund |
| **Seller Wins** | Payment released |
| **Partial Resolution** | Split decision |
| **Return Required** | Return goods |
| **Further Investigation** | Extended review |

**Decision Factors**:
- Evidence quality
- Transaction history
- Platform policies
- User history
- Applicable laws

### Step 6: Appeal

**Appeal Process**:
1. Review decision
2. Gather new evidence
3. Submit appeal within 14 days
4. Higher-level review
5. Final decision
