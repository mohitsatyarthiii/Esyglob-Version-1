# International Shipping - Complete B2B Guide 2026

## Overview

International shipping is a critical component of global trade. This guide covers everything B2B businesses need to know about shipping products across borders.

## Shipping Methods Comparison

| Method | Speed | Cost | Best For | Capacity |
|--------|-------|------|----------|----------|
| **Sea Freight** | 15-45 days | Low | Bulk orders | Full containers |
| **Air Freight** | 3-7 days | High | Urgent orders | Palletized |
| **Express Courier** | 2-5 days | Very High | Samples, small parcels | Small packages |
| **Rail Freight** | 18-25 days | Medium | Eurasia route | Containers |
| **Truck Freight** | 5-15 days | Medium | Regional | Full truckload |

## Detailed Shipping Methods

### 1. Sea Freight

**Best For**:
- Large volumes
- Non-urgent shipments
- Heavy/bulky goods
- Cost-sensitive shipments

**Container Types**:

| Container | Dimensions | Capacity | Best For |
|-----------|------------|----------|----------|
| **20ft Standard** | 20' x 8' x 8.6' | 28 CBM | General cargo |
| **40ft Standard** | 40' x 8' x 8.6' | 67 CBM | General cargo |
| **40ft High Cube** | 40' x 8' x 9.6' | 76 CBM | Volumetric cargo |
| **Reefer** | 20/40ft | Varies | Temperature-sensitive |
| **Open Top** | 20/40ft | Varies | Overheight cargo |
| **Flat Rack** | 20/40ft | Varies | Heavy/oversized |

**Cost Factors**:
| Factor | Impact |
|--------|--------|
| **Route** | Major routes cheaper |
| **Season** | Peak season higher |
| **Volume** | Bulk discounts |
| **Fuel** | Bunker adjustment |
| **Currency** | Exchange rates |

**Major Shipping Routes**:

| Route | Transit Time |
|-------|--------------|
| **China to USA (West Coast)** | 15-20 days |
| **China to USA (East Coast)** | 25-30 days |
| **China to Europe** | 25-30 days |
| **India to USA** | 20-25 days |
| **India to Europe** | 18-22 days |

### 2. Air Freight

**Best For**:
- Urgent shipments
- High-value goods
- Perishable items
- Small volumes

**Air Freight Types**:

| Type | Description | Best For |
|------|-------------|----------|
| **Standard** | Regular cargo | General goods |
| **Express** | Priority handling | Urgent shipments |
| **Charter** | Dedicated aircraft | Large/heavy cargo |
| **Dangerous Goods** | Special handling | Hazardous materials |

**Cost Factors**:
| Factor | Impact |
|--------|--------|
| **Weight** | Chargeable weight (actual vs volumetric) |
| **Volume** | Volumetric weight calculation |
| **Route** | Major hubs cheaper |
| **Season** | Peak seasons higher |

**Volumetric Weight Calculation**:
Volumetric Weight (kg) = (Length x Width x Height in cm) / 6000

Example: 100cm x 80cm x 60cm = 480,000 / 6000 = 80 kg

## Shipping Documents

### Essential Documents

| Document | Description | Required? |
|----------|-------------|-----------|
| **Commercial Invoice** | Transaction details | Always |
| **Packing List** | Package contents | Always |
| **Bill of Lading (B/L)** | Sea transport document | Sea freight |
| **Air Waybill (AWB)** | Air transport document | Air freight |
| **Certificate of Origin** | Country of origin | Usually |
| **Insurance Certificate** | Transit insurance | Recommended |
| **Import/Export License** | Required for restricted goods | Sometimes |

### Bill of Lading (Sea Freight)

**Types**:
| Type | Description |
|------|-------------|
| **Original B/L** | Title document, 3 copies |
| **Surrender B/L** | Electronic release |
| **Sea Waybill** | Non-negotiable |
| **Straight B/L** | Only to named consignee |

### Air Waybill (Air Freight)

**Features**:
| Feature | Description |
|---------|-------------|
| **Issued By** | Airline or freight forwarder |
| **Not Negotiable** | Not a title document |
| **Tracking** | Unique AWB number |

## Shipping Cost Calculation

### Total Cost Components

| Component | Description | Responsible Party |
|-----------|-------------|-------------------|
| **FOB Price** | Product cost | Buyer |
| **Ocean/Air Freight** | Transport cost | Depends on Incoterm |
| **Insurance** | Cargo insurance | Depends on Incoterm |
| **Customs Duties** | Import tariffs | Buyer/Depends |
| **Customs Brokerage** | Customs clearance | Buyer |
| **Terminal Handling** | Port charges | Buyer/Depends |
| **Inland Freight** | Door delivery | Buyer/Depends |

| Document | Purpose |

## Shipping Insurance

### Insurance Types

| Type | Description | Coverage |
|------|-------------|----------|
| **All Risks** | Broadest coverage | Most perils |
| **WA (With Average)** | Partial loss coverage | Partial losses |
| **FPA (Free of Particular Average)** | Limited coverage | Major losses |

### Insurance Cost

**Calculation**:

Insurance Premium = (CIF Value + 10%) × Premium Rate

Example:
CIF Value: $10,000
Add 10%: $11,000
Premium Rate: 0.5%
Premium: $55
